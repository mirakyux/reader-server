## 行为保护与修改边界

1. 先增加目录重排／插入后的缓存身份、并发保存、非默认存储根和 Cookie 登录账户隔离回归。上一轮浏览器模拟已复现搜索混合、发现响应竞态、Escape 丢稿和账户缓存共用；将这些行为加入正式回归后再修实现。
2. 后端统一存储根，复用现有原子文件写入与按文件加锁模式。书源／书架读改写统一事务，网络调用在事务之外，写回合并最新数据。正文、编辑、原文备份和 metadata 与章节身份一致；目录变化不能复用错误正文。兼容旧缓存和旧目录，不对主数据执行批量删除。
3. 搜索翻页使用已提交查询快照，查询变更明确提示新搜索。发现切源／分类时取消或忽略旧请求；忙碌状态覆盖全部在途操作，避免旧响应更新新页面。
4. 已认证账户身份与是否持久保存 token 分开，缓存和待同步进度按 API 与真实用户隔离。登录、登出、恢复 Cookie 会话和切换服务器都有保护；默认匿名空间保持独立。
5. 书源编辑关闭时保护未保存草稿。书源桌面列表保留常用操作，其余收进菜单；手机改成卡片，启用／编辑可直接访问，批量与筛选仍保留。设置按连接账户、阅读、缓存导出、同步、统计分组，不增加常驻侧栏。复用已有组件，删除重复呈现及无效样式。

## 分工与验证

- 后端执行者拥有后端源文件与后端回归；前端交互执行者拥有 Library、Common 与搜索／发现回归；书源页面执行者拥有 Sources、对应样式和书源页面回归。主执行者拥有账户／缓存／设置分组与整体集成。共享文件变化先协调，Gradle 由主执行者串行运行。
- 确认新增回归在旧实现失败，再运行修复后的定向检查。最终执行后端完整测试与打包、前端 lint／typecheck／单元测试／完整浏览器测试／生产构建，以及 QuickJS、浏览器桥、阅读缓存、TXT／EPUB、同步备份真实隔离联测。
- 每轮 UI 编辑后检查 1440、390、320 像素截图，记录可见入口、横向溢出、菜单键盘与焦点、未保存提示、设置分组可达性。视觉判断写入 `.omx/state/quality-fixes/ralph-progress.json`；使用当前 App 可用的浏览器与图像工具完成检查。
