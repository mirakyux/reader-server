# FU 非 AI 功能补齐计划

## 当前范围

按用户 2026-10-09 的最新要求，对齐书源、阅读、设备离线、RSS、净化／查词、外观和数据同步。AI／Skills／MCP、听书不补齐；本地书格式和解析暂缓；TXT／EPUB 保留当前下载方式，不增加远程导出。已有能力和用户数据保留。

参考仓库 `E:/workspace/Java/legado_FU` 只读。当前工作区已有迁移修改，禁止重置或覆盖。没有新依赖；优先复用现有解析器、HTTP、用户存储、缓存和浏览器。

## 实施分工

1. 书源：补规则执行、目录和正文登录检查、HTTP／JS 桥、动态登录／发现、全阶段校验、编辑／调试、源管理及订阅。
2. 阅读：补净化开关、位置／书签／搜索定位、换源、分页、正文编辑、查词、漫画操作、排版／书架布局／主题包、设备完整离线和预读。
3. RSS 和数据：补实际分页、搜索／登录、收藏／历史／离线／分组／排序／调试；补 FU 阅读记录和备份转换、远程 WebDAV 客户端、进度冲突处理及自动备份。
4. 主任务：实现章内进度和换源／单章换源后端、持久正文编辑和词典规则服务，整合接口，检查取消传播，负责最终验收。

各子任务有独立写入范围，公共 API 路由和 BookController 由主任务整合。各功能做必要拆分，避免无关重构，不增加常驻侧栏或一屏工具按钮。

## 修改前的回归

先用固定样例保护字符位置、进度冲突、目录匹配、章节编辑恢复和词典解析。书源以本地 HTTP／动态页面验证预处理、登录失败恢复、网页规则和完整校验；前端保护单书开关、搜索／书签定位、分页和离线冷启动。RSS 和备份用隔离用户数据验证分页／历史／格式转换及回滚。

## 验收与收尾

先跑定向测试，再统一 lint、typecheck、前端单元和 Edge 浏览器回归、后端完整测试／构建、浏览器服务测试。同一目录不并发运行 Gradle。测试只写隔离工作目录，主书架与书源做只读身份核对。

最后更新对照矩阵及实际验证证据，重启主服务使改动生效。Android 硬件控制和实验性引擎按实际可用实现说明，不把保存字段或显示按钮当成完成。远程 WebDAV 用本地协议服务器联测，不写用户尚未配置的外部服务。
