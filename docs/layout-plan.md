# 阅读首页与导航整理

本轮按用户确认的布局调整实施：取消常驻左侧菜单，顶部保留“书架、找书、更多”。界面以继续阅读和书籍列表为中心，书源与其他管理功能归入工具菜单。

## 修改顺序

1. 先运行已有移动页面、批量管理和本地导入回归，保护路由与原有操作。
2. 删除侧栏及手机底部重复导航，桌面和手机共用顶部入口。“找书”包含搜索与发现，“更多”按阅读工具和管理设置分组。
3. 书架保留导入入口，将更新、批量及分组管理收进管理菜单。压缩顶部说明和继续阅读卡片，给书籍列表留出更多空间。
4. 删除失效样式，复用已有 Radix 菜单、按钮和页面路由，不添加依赖，不修改后端及用户数据。

## 验证

验证所有工具页可从菜单进入；菜单可用键盘打开、选择和关闭，并恢复焦点。检查“找书”内搜索与发现切换、书架管理及原有阅读流程。

运行前端 lint、类型检查、单元测试、完整浏览器回归和生产构建。检查桌面、390 像素手机及 320 像素窄屏截图，确保导航不换行溢出、首屏突出阅读，菜单内工具可访问。

## 验收结果

已完成顶部导航、找书内搜索/发现切换、分组工具菜单和书架管理菜单。删除旧侧栏、底部导航、重复入口和失效样式，不增加依赖。

原有 4 项相关流程基线通过。修改后 38 项单元测试、34 项完整浏览器回归、ESLint、TypeScript 和生产构建全部通过。新增回归覆盖桌面及 320 像素宽度的全部工具入口、键盘导航、Escape 后焦点恢复、分组管理及搜索/发现请求。

实际服务截图检查覆盖 1440、390 和 320 像素宽度，页面与工具菜单均无横向溢出，页面错误为空。手机书籍列表起点约为 455～463 像素，首屏可以看到书籍。证据保存在 `web/logs/layout-browser.log`、`layout-quality.log`、`layout-live.log` 和 `web/screenshots/layout-*.png`。

主要修改文件为 `web/src/App.tsx`、`web/src/components/Library.tsx`、`web/src/styles.css`、导航回归和截图脚本。工具入口由“更多”展开；部署生产环境需使用本轮重新构建的 `web/dist`。
