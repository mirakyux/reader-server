# 详情、阅读操作与换源修复

本轮处理详情章节数为空、正文前操作栏占位、换源入口不明显，以及真实部署验收发现的同 URL 换源缓存问题。内网实例地址为 `http://192.168.31.107:4396/`。

## 交互变化

- 详情缺少章节数时读取实际目录，显示加载状态与失败重试。书架已有完整信息时直接复用；异步结果保留用户正在编辑的书名、封面和设置。
- 正文前的书籍链接、作者标签与书源动作移入阅读页顶栏的“更多阅读操作”。复制、分享、书源阅读事件、图片解码与按需段评继续使用现有实现。
- 阅读页顶栏增加带文字的“换源”；书架右键/更多菜单与书籍详情也提供“切换书源”。复用同一弹窗，显示当前源、候选、进度及错误重试。
- 无候选时自动搜索首批；“查找更多书源”继续检索。只接受同名同作者的候选。整书换源匹配章节标题；“只换本章”在下一章自动回原源。
- 手机换源按钮位于书源信息下方，详情底部按钮可换行。菜单位于复制提示上方，避免提示挡住连续操作。

## 代码变化与简化

- `web/src/components/Library.tsx`：详情加载、章节计数、书架/详情入口与底部换行。
- `web/src/components/ChangeSource.tsx`：共用换源弹窗，替代阅读页内嵌实现，统一搜索、取消、确认、错误与重试。
- `web/src/components/Reader.tsx`、`web/src/lib/cache.ts`：换源时暂停旧进度写入，重新读取新源目录与正文；新源失败时不能回退到旧源缓存。
- `web/src/components/SourceFeatures.tsx`：将正文前大按钮收进顶栏菜单，结果使用独立弹窗。
- `web/src/lib/clipboard.ts`：复用原生浏览器复制能力，兼容内网 HTTP，无新增依赖。
- `web/src/App.tsx`、`web/src/styles.css`：提示与菜单层级，以及顶栏在手机上的布局。
- `BookController.kt`、`ChapterCache.kt`、`ChapterEdits.kt`、`BookHelp.kt`：候选按书源和书籍 URL 共同去重；目录、正文、图片与章节编辑共用源身份缓存路径，书架当前源优先于旧书籍信息缓存。
- `web/tests/browser/book-details.spec.ts`、`source-switch.spec.ts`、`reader-tools.spec.ts` 及 `web/tests/clipboard.test.ts`：保护异步编辑、同 URL 换源、失败缓存隔离、连续复制及响应式布局。
- `web/scripts/check-source-fix-deployment.mjs`：真实内网 API/UI 验收，只创建唯一分组的两条临时书源与一本测试书，结束后精确清理并核对原数据保留。

前端 107 项完整浏览器回归、lint、typecheck、81 项单元测试与生产构建通过。后端 240 项测试通过，包括同 URL 的整书/临时换源、原源编辑恢复、清一个源的缓存不影响另一个源、TXT/EPUB 正文隔离、旧缓存升级和并发图片加载。生产离线验证覆盖缓存正文、目录、图片、关闭页面后的离线启动及账号隔离。1440、390、320 像素截图检查保存在 `screenshots/reader-source-fix/`，结果为 `.omx/state/reader-detail-source/ralph-progress.json`。

内网真实 API/UI 已通过章节数、单章换源、整书换源、刷新保持阅读位置及书架/详情入口验收。TXT 与 EPUB 解压后的四章正文均为 B 源，无 A 源旧正文。原书《人在死牢马甲成圣》的 452 章目录及正文（首章 4936 字符）可正常读取，发布的页面与本地生产构建一致。测试数据已精确清理，原有 1 本书与 600 条书源全部保留。证据为 logs/source-fix-deployment.json、logs/reader-original-book.json；详细改动和检查日志随工作区保存。

## 部署与边界

仅更新本项目 API 和 Web，保留 `.env`、书架、书源与日志；浏览器桥接服务以及服务器其他应用不重启。先构建新镜像，再短暂停 API 保存 storage 一致快照并升级；保存旧镜像与 Compose 配置，发布包经 SHA-256 校验。

旧版没有书源归属标记的缓存与编辑文件仍原位保留，升级后不能确定其属于哪个源时不会自动复用。当前源需要重新获取目录和正文；导出之前仍需完成全书缓存。新版本明确归属的缓存与编辑可以在切回该源时继续使用。

外部书源的结果仍取决于源站及规则是否可用；无候选或失败会明确显示，支持继续查找与重试。本轮没有新增 AI、听书、Android 动态场景或远程导出功能。
