# React 前端迁移计划

1. 从旧 Vue 页面和后端路由核对 API 契约，先锁定认证参数、错误响应、阅读进度、书源 JSON 导入和本地书导入回归。
2. 用 React、TypeScript、Vite、shadcn/ui、Radix、Tailwind CSS 替换 Vue 2、Vue CLI、Element UI、Axios 和 LocalForage；采用 MIT 开源组件及原生 fetch、IndexedDB，删除旧框架配置及源码。
3. 独立部署前端；开发运行在 5173 并代理 `/reader3`、`/assets` 到 8080，生产通过 `VITE_API_BASE_URL` 配置 API。
4. 保留书架与分组、搜索与发现、阅读与听书、目录与换源、书源管理/编辑/调试/导入、书签、替换规则、RSS、书仓、本地书导入、WebDAV、用户设置与缓存。
5. 优先补书源管理能力；扩展接口接入以真实后端契约为准，不展示无法执行的功能。
6. 运行单元回归、类型检查、ESLint、生产构建及浏览器验证。

收尾核对：锁定登录动作返回新表单与状态、RSS 首分类、本地 TXT/EPUB 目录规则的浏览器回归；复用旧简繁映射，补齐字重与段间距，接回书架批量分组/移除及分组排序，不增加依赖。

能力补齐按独立模块推进：

1. 先保护已有 React 配置与旧 Vue `config` / `customConfigList`；补自定义字体、背景上传与 URL、方案保存切换删除导入导出，服务器备份合并保留旧字段。
2. 对接后端已落地的 AI 配置、净化、流式助手、Skills、MCP、角色语音与阅读统计；以真实接口状态控制可执行操作。
3. 按后端契约接书源动作、发现筛选、付费目录与文件下载列表；扩展替换规则作用范围和范围书签高亮，保持章节进度与导出兼容。

依赖版本从 npm 官方注册表当前 stable 标签核验。旧本地书后端实际支持 TXT/EPUB/UMD/CBZ，不支持 PDF；界面按接口真实能力展示。

高级功能采用原生 fetch 的 POST SSE、FontFace、Web Worker、Audio 和浏览器可见性事件实现，不新增运行时依赖。书源浏览器使用服务器截图与点击/键盘操作，关闭时保存会话；普通 HTTP 及缓存、调试、搜索 SSE 请求尚未返回时，每秒获取待处理交互。正常完成或服务器错误时停止轮询并最后获取一次交互，显式取消时抑制迟到动作，支持验证完成后继续原请求。

同源 EPUB 章节已接入实际文字选区、半开字符范围书签、跨章节高亮恢复和返回原文定位。字体、背景和简繁设置与普通正文共用；朗读、助手选中上下文和阅读字数估计读取 iframe 内的可见正文。同源 HTML 与 XHTML 均保留原排版和节点命名空间，重新应用标记前恢复净化后的原始内容。iframe 保持仅 `allow-same-origin` 沙箱权限，不执行章节脚本或事件属性；跨域章节的 DOM 操作受浏览器限制。
